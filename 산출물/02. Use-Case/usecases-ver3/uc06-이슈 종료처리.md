# UC06 이슈 종료처리

| 항목 | 내용 |
| --- | --- |
| Use-Case Name | 이슈 종료처리 |
| Level | User-Goal |
| Primary Actor | PL |
| Stakeholders and Interests | PL: 수정이 끝난 이슈를 종료처리하고 싶음 |
| Preconditions | PL이 인증된 상태이다. |
| Success Guarantee | 선택한 이슈가 ‘Closed’ 상태로 저장된다. |
| Main Success Scenario | 1. 이슈 브라우즈(UC7)를 include하여 PL이 ‘Resolved’ 상태인 이슈를 확인한다.<br>2. PL이 이슈의 상태를 ‘closed’로 변경한다. |
| Extensions | 2a. ‘Resolved’가 아닌 이슈의 상태 변경을 시도한다.<br>1. System이 요청을 거절한다 |
| Miscellaneous | 예제 시나리오: PL1은 resolved 상태인 이슈들을 선택해서 closed로 바꿈. |
