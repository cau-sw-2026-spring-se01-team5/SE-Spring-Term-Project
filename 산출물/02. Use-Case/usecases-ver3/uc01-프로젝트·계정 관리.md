# UC01 프로젝트·계정 관리

| 항목 | 내용 |
| --- | --- |
| Use-Case Name | 프로젝트·계정 관리 |
| Level | User-Goal |
| Primary Actor | Admin |
| Stakeholders and Interests | Admin: 프로젝트를 생성하고 각 Role에 해당하는 계정을 추가 및 관리하고 싶음<br>PL/dev/tester: 운영에 필요한 계정이 준비되길 바람 |
| Preconditions | Admin이 인증된 상태이다. |
| Success Guarantee | 프로젝트가 생성된다.<br>Role이 지정된 계정이 생성 및 저장된다. |
| Main Success Scenario | 1. Admin이 프로젝트명을 설정해 생성 후 입장한다.<br>2. System이 프로젝트를 저장한다.<br>3. Admin이 Role(PL/dev/tester)과 계정 정보를 입력한다.<br>4. System이 계정을 저장하고 Role을 반영한다. |
| Extensions |  |
| Miscellaneous | 예제 시나리오: Admin이 project1을 추가함. 또한 PL계정, 개발자 계정, 테스터 계정을 추가함. |
