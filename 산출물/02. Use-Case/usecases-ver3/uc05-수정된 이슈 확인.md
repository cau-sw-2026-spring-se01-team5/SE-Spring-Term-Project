# UC05 수정된 이슈 확인

| 항목 | 내용 |
| --- | --- |
| Use-Case Name | 수정된 이슈 확인 |
| Level | User-Goal |
| Primary Actor | Tester |
| Stakeholders and Interests | Tester: 자신이 보고한 이슈 중 수정이 완료된 것을 찾아 해당 이슈를 종료 처리하고 싶음 |
| Preconditions | Tester가 인증된 상태이다. |
| Success Guarantee | 선택한 이슈의 Status가 Resolved로 변경된다. |
| Main Success Scenario | 1. 이슈 브라우즈(UC7)를 include하여 tester가 자신이 report한 이슈 중 ‘fixed’ 상태인 이슈를 확인한다.<br>2. 이슈의 상태를 ‘Resolved’로 변경한다. |
| Extensions | 2a. ‘fixed’가 아닌 이슈의 상태 변경을 시도한다<br>1. System이 요청을 거절한다. |
| Miscellaneous | 예제 시나리오: tester1은 자신이 report하였던 이슈 중에 fixed된 이슈들을 검색<br>→ 적절히 고쳐진 이슈들을 선택하여 “resolved” 상태로 바꿈. |
