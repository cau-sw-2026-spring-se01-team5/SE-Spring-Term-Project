# UC04 배정된 이슈 해결

| 항목 | 내용 |
| --- | --- |
| Use-Case Name | 배정된 이슈 해결 |
| Level | User-Goal |
| Primary Actor | dev |
| Stakeholders and Interests | dev: 자신에게 배정된 이슈를 확인 후 수정하고 결과를 코멘트에 남기고 싶음 |
| Preconditions | Dev가 인증된 상태이다. |
| Success Guarantee | Fixer에 수정을 진행한 dev의 아이디가 저장된다. |
| Main Success Scenario | 1. 이슈 브라우즈(UC7)를 include하여 dev가 자신에게 배정된 이슈를 확인한다.<br>2. 코드 수정 등 실제 수정은 별도 도구에서 진행한다<br>3. 코멘트 추가(UC8)를 include하여 dev가 필요한 코멘트를 남길 수 있다<br>4. Dev가 Status를 ‘fixed’로 변경한다<br>5. System이 fixer를 해당 dev로, Status를 ‘Fixed’로 수정한다. |
| Extensions |  |
| Miscellaneous | 예제 시나리오: dev1은 이슈 검색 기능으로 자신에게 assign 되어 있는 이슈들을 브라우즈<br>→ 이슈들에 대해 남겨진 코멘트를 포함하여 다양한 정보를 확인하고<br>→ 코드를 고친 후 코멘트를 추가한 후 해당 이슈를 fixed로 바꿈<br>→ 해당 이슈의 fixer는 dev1으로 등록됨. |
