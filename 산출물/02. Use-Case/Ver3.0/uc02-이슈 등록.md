# UC02 이슈 등록

| 항목 | 내용 |
| --- | --- |
| Use-Case Name | 이슈 등록 |
| Level | User-Goal |
| Primary Actor | tester |
| Stakeholders and Interests | tester: 버그 또는 요청 사항을 등록하고 싶음<br>PL/dev: status가 new인 이슈들을 확인해 작업 대상들을 보고 싶음 |
| Preconditions | tester에게 권한이 부여되어 있다 |
| Success Guarantee | 이슈가 저장되고 식별자가 주어진다.<br>Reporter, Reported Date가 자동으로 시스템에 입력된다.<br>기본 상태는 ‘new’이다. |
| Main Success Scenario | 1. Tester가 새로운 이슈의 제목과 설명, Priority를 입력한다.<br>2. 코멘트 추가(UC8)을 include하여 tester가 필요한 코멘트를 남길 수 있다.<br>3. System이 tester의 계정을 Reporter로, 입력한 시간을 Reported Date로 반영해 ‘new’ 상태로 저장한다. |
| Extensions | 1a. 제목 또는 설명이 비었다<br>1. System이 등록을 거절한다. |
| Miscellaneous | 예제 시나리오: tester1이 이슈를 하나 생성<br>→ 해당 이슈의 코멘트를 하나 추가함<br>→ 시스템은 해당 이슈의 상태를 new로 변경하고, reporter의 값은 tester1으로 저장 |
