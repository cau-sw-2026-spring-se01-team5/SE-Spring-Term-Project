# 유스케이스 정리

보고서에 넣을 건 아니고 그냥 팀원들 보기 편하라고 만듦

수정사항 -> 각 기능 별로 쪼개는 것이 아닌, primary actor의 goal을 기준으로 재구성해야할 듯

## 2) Include / Extend 관계

각각 최소 2개 이상 들어가야 함

| 관계 | Base | Related | 설명 |
| --- | --- | --- | --- |
| **include** | Register Issue (UC2) | Capture Actor and Timestamp (UC3) | reporter/reported date 자동 기록을 수행 |
| **include** | Examine Issue (UC6) | Capture Actor and Timestamp (UC3) | 이슈 수정한 사람/date 자동 기록을 수행 |
| **include** | Examine Issue (UC6) | Validate Issue State Transition (UC5) | 상태 변경 가능 여부 확인 |
| **extend** | Examine Issue (UC6) | Recommend Assignee Candidates (UC7) | PL이 assignee 추천을 요청할 때만 수행 |
| **extend** | Recommend Assignee Candidates (UC7) | Trigger Recommendation Learning (UC8) | 추천 품질 개선이 필요할 때만 수행 |

### 1) Include를 사용한 이유

include는 **반복적으로 사용되는 sub기능**을 분리할 때 사용했음

### (a) Register Issue (UC2) / Examine Issue (UC6) → Capture Actor and Timestamp (UC3)

- 현재 작업자와 현재 시각을 읽는 작업은 새로운 이슈 등록/수정에서 반복된다.
- 신규 등록에서는 Reporter/Reported Date로 사용하고, 수정/코멘트에서는 작성자/작성시각으로 씀

### (b) Examine Issue (UC6) → Validate Issue State Transition (UC5)

- 상태 변경 검증(현재 상태, 대상 상태, 역할 권한)은 상태가 바뀔 때마다 반복되는 규칙이다.
- 해당 권한을 가진 사람이 이 상태 변경을 할 수 있냐를 확인

---

### 2) Extend를 사용한 이유

extend는 **base UC를 수정하지 않고 선택 기능만 독립적으로 변경**하려고 사용

### (a) Recommend Assignee Candidates (UC7) → Examine Issue (UC6)

- 모든 이슈 상세 조회 추천에서 담당자 후보 추천이 필요한건 아님
- 추천을 extend로 분리해서 base를 수정하지 않고 실험/개선 가능하도록 함

### (b) Trigger Recommendation Learning (UC8) → Recommend Assignee Candidates (UC7)

- 학습 기능을 extend로 분리해서 필요할 때만 실행
- 발표 때 이 작업을 보여줘야 한다고 적혀있음

## 4) 과제 기능 ↔ 유스케이스 매핑

| 과제 기능 | 반영 위치 |
| --- | --- |
| 1. 계정 추가(역할) | UC1 프로젝트 및 사용자 계정 관리하기 |
| 2. 이슈 등록(Title/Description 필수, Reporter/Reported Date 자동) | UC2 이슈 등록하기 + UC3 행위자 및 현재 시각 기록하기 |
| 3. 이슈 브라우즈 및 검색 | UC4 이슈 조회 및 검색하기 |
| 4. 이슈 코멘트 추가 | UC6 이슈 상세 확인 및 수정하기 |
| 5. 이슈 상세 정보 확인(필드+코멘트 history) | UC6 이슈 상세 확인 및 수정하기 |
| 6. 이슈 배정 포함 상태 변경 | UC6 이슈 상세 확인 및 수정하기 + UC5 이슈 상태 변경 검증하기 |
| 7. 이슈 통계 분석(일/월 트렌드) | UC4 Miscellaneous(동일 데이터 집계 화면) |
| 8. 해결 이력 기반 assignee 추천 | UC7 담당자 후보 추천하기 + UC8 추천 학습 수동 실행하기 |
